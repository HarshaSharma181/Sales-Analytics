# 📊 Sales Analytics – Excel

## 📌 Project Overview

This repository contains **Sales Analytics and Business Intelligence reports created using Microsoft Excel for AtliQ Hardware**. The reports provide insights into sales, profitability, customer growth, and market performance.

---

## 📈 Excel Sales Reports

### 1. P&L Statement by Months

The **P&L Statement by Months** provides month-wise and quarterly financial analysis across different fiscal years.  
It tracks **Net Sales, COGS, Gross Margin, and GM%** and enables comparison of FY 2019, FY 2020, and FY 2021 performance.

#### Monthly P&L Views

![P&L Statement by Months - View 1](Images%20-%20Excel%20Project/P%26L%20Statement%20by%20Months-images-0.jpg)

This view presents the monthly P&L analysis and provides a detailed breakdown of financial performance across the reporting period.  
It helps compare sales, cost, and gross margin trends across individual months.

![P&L Statement by Months - View 2](Images%20-%20Excel%20Project/P%26L%20Statement%20by%20Months-images-1.jpg)

This view provides another perspective of the monthly financial analysis, supporting comparison of sales and profitability trends.  
It helps identify changes in business performance across different periods.

![P&L Statement by Months - View 3](Images%20-%20Excel%20Project/P%26L%20Statement%20by%20Months-images-2.jpg)

This view further highlights the monthly P&L information and supports detailed financial performance analysis.  
It can be used to evaluate changes in Net Sales, COGS, Gross Margin, and GM%.

![P&L Statement by Months - View 4](Images%20-%20Excel%20Project/P%26L%20Statement%20by%20Months-images-3.jpg)

This view completes the monthly P&L analysis by providing an additional period-level perspective.  
Together, the four views provide a comprehensive picture of month-wise financial performance.

### 3. P&L Statement by Markets

### 4. Market Performance Vs Target

![Market Performance Vs Target](Images%20-%20Excel%20Project/Market%20Performance%20Vs%20Target.jpg)

### 5. Customer Performance Report

![Customer Performance Report - View 1](Images%20-%20Excel%20Project/Customer%20Performance%20Report-image-1.jpg)

![Customer Performance Report - View 2](Images%20-%20Excel%20Project/Customer%20Performance%20Report-images%202.jpg)

## 🔎 Key Insights

- Strong revenue growth was observed in **FY 2021**.
- **India and USA** were among the top-performing markets.
- Significant improvement was observed in **customer sales performance**.
- The reports provide useful insights for **business planning and performance tracking**.
